## 📝 Client Intake Form

The `intake-form.html` file is a fully functional, multi-step client intake form connected to **Formspree** (`info@carlabee.com`). It collects:

- Contact information
- Business details
- Website goals & pages needed
- Design preferences (colors, fonts, vibe)
- Content & media availability
- Domain & hosting status
- Timeline

Submissions go directly to **info@carlabee.com** within minutes of the client completing the form.

## 🔧 How to Update This Site

### To update text content:
1. Go to the file in GitHub (e.g. `index.html`)
2. Click the **pencil icon** to edit
3. Make your changes
4. Click **Commit changes**

### To add a new sample site:
1. Upload the new `.html` file to this repo
2. Add a new card in the `portfolio-grid` section of `index.html`
3. Commit changes — the site updates automatically

### To add a new page to the intake form:
- Edit `intake-form.html` and add a new `<div class="section-card">` block
- Update the `goTo()` function and `TOTAL` variable to match the new count
